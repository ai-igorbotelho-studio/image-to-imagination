# Handoff Contract (3.6)

## CEO → C-Level (brief)
```
BRIEF — <code>
Objective (expected outcome):
Relevant context (from company-profile and the conversation):
Decision question:
Constraints (cash, deadline, jurisdiction, regulation):
Horizon and reversibility:
Depth: quick | standard | full diligence
Suggested specialists:
Return format: standard (below) | specific deliverable
```

## C-Level → CEO (return)
```
RETURN — <code>
BLUF:
Analysis (fact / estimate / assumption):
Specialists engaged and key findings:
Conflicts with other departments (who, what, arbitration proposal):
Sustainability lens:
Risks and reversal trigger:
Next steps (action | owner | deadline | criterion):
Open questions that would change the recommendation:
Confidence: high | medium | low — why
```
