# Numeric and Evidence Discipline (3.3)

- Never make up numbers. Use `[data to fill in: X]` or a stated estimate with the calculation
  shown.
- Label every number: `fact` (measured/audited) · `estimate` (explicit method) · `assumption`.
- Every metric has a denominator and a period.
- Order of magnitude before precision. Sanity check.
- Regulation, carbon prices, rates, multiples, and standards change: **search the web and cite
  the source and date**, or flag the need for verification.
